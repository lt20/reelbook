## What
Signing out of the app (Sign out, « another backend ») signs out this device only. When the computer's session is
revoked anyway (password changed, sign-out everywhere), `rb.py` says « Your computer was signed out of Reelbook
(session revoked). Run: python3 <this rb.py, ~ for home> login » and exits 3; the night run's phone notice says
« Reelbook night run: signed out, run rb.py login ». README: one line under Overnight.

## Why
4 Nov: `rb.py backfill-tags` answered `POST …/auth/v1/token → 400 refresh_token_not_found`. supabase-js v2
`auth.signOut()` defaults to `scope: 'global'`, which revokes every refresh token of the account, the one rb.py keeps
in `~/.config/reelbook` too, so the night run failed with a bare « rb.py queue failed ».

## Decisions
- supabase-js vendored is 2.49.4 (auth-js 2.69.1): `signOut({scope})` is supported (`local` = POST /logout?scope=local,
  revokes only this session's refresh token).
- rb.py treats as revoked a 400/401/403 on refresh whose body holds `refresh_token_not_found`,
  `refresh_token_already_used`, `invalid_grant`, `Invalid Refresh Token`, `session_not_found` or `session_expired`;
  any other refusal keeps the raw answer (exit 1).
- Exit code 3 (`rb.SIGNED_OUT`) is the contract with nightly.sh; `queued()` now returns rb.py's exit code.
- The other failure notice reads « Night run: rb.py queue failed (exit N) » (was « … (signed out?) »).
- The login command names the running rb.py (`~` for home), not a fixed `~/dev/reelbook`: install.sh defaults to
  `~/reelbook` (Codex pass 2).
- Not fixable here (Codex pass 2): the first launch of an installed PWA after the deploy still runs the cached old
  page (stale-while-revalidate), whose Sign out is global; from the next launch on, local. Bumping VERSION does not
  shorten that window (the new page is cached in the background either way).

## Pitfalls
- Arguments passed into the harness page come from another realm (vm): copy them (JSON) before `deepEqual`.
- A session revoked mid-run (after Claude starts) is caught by the closing `rb.py list` (exit 3 → signed-out
  notice, Codex pass 1 « attention »); that branch is checked by `bash -n` only.
