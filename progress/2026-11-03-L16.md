## What
- New template `templates/technique.html` for a trick worked by tries: Prerequisites → Conditions → (Roles) →
  Go / no-go box → Steps → Common mistakes → Key points → Try plan → Safety box → (Control / tap) → source.
  Roles and Control / tap are for the `partner` profile only.
- The sheet page shows a technique sheet header → go / no-go → steps → the rest in its order (`app/sheet.js`,
  told by the `.gonogo` box). Gym sheets are arranged as before.
- Each library notebook in `app/config.js` has a `profile` (gym | technique | partner); `rb.py themes` adds it to
  each line (custom notebook: gym). The skill picks the template from it.
- CSS block « L16 » (prerequisites, conditions grid, roles, go / no-go, safety). A Kitesurf sheet « Backroll » in the
  preview fixtures.

## Why
Audit E6: a kitesurf trick got a gym dose grid (« 3–5 essais », « lent », « 12 h »).

## Decisions
- Profiles: technique = kitesurf, kitefoil, wingfoil, wakeboard, surf, climb, snow, ride, pole; partner = fight;
  gym = the 19 others (dance is solo; swimming, running, racket sports keep doses).
- Try plan uses the `.dose` grid (same look); in a technique sheet it is not pulled up after the steps.
- Conditions use their own `.cond` class, so a technique sheet without its go / no-go box still finds the try plan
  as its dose and not the conditions.
- Key points kept (optional) on the technique template: the session player reads them (L10).
- The app exposes `profile` on its theme objects (read from the library by id) but does not use it yet.
- French labels: Prérequis, Conditions, Go / no-go, Plan d'essais, Sécurité, Rôles, Contrôle / abandon.
