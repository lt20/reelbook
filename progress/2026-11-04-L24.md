## What
A quiet card at the top of the home page (above search and notebooks) invites to install the app while it runs in
a browser tab, for a signed-in user whose catalogue loaded with at least one sheet:
- iOS Safari: share glyph + « Install Reelbook: tap Share, then Add to Home Screen » + « Not now »;
- Chromium: « Install Reelbook on this device: it opens full screen, like an app. » + « Not now » + « Install »
  (`prompt()` of the kept `beforeinstallprompt` event), shown only once the browser fires that event;
- other browsers, the installed app (`navigator.standalone` or `display-mode: standalone`), a notebook page, a failed
  catalogue: nothing.
« Not now » stores `rb.install.dismissed` (ISO date, device-level) and hides the card for 30 days.

## Why
Audit O4: the app works best installed (keep screen on, rest timer, full screen) and nothing said so.

## Decisions
- The card lives inside `#home`, so it is never on the auth screen, a sheet or the player; `renderInstall` runs at
  the end of `renderHome` and on `beforeinstallprompt` / `appinstalled`.
- The share glyph sits at the start of the card, not inside the sentence: the acceptance test matches the sentence
  as one run of HTML (« tap Share, then »).
- iOS Safari = iPhone / iPod / iPad UA (or iPadOS's desktop UA with touch) with `Version/… Safari/`, not CriOS,
  FxiOS, EdgiOS, OPiOS.
- `matchMedia` and the window events are guarded (`typeof window.matchMedia`); the harness has neither.

## Pitfalls
- In `route`, `renderHome()` runs before `show('home')`: `renderInstall` cannot test `#home.hidden`.
- Chromium `prompt()` refused (Codex pass 2): the event is spent, so the card stays with « The install window did
  not open. Install Reelbook from your browser menu instead. » and « Not now »; a new `beforeinstallprompt` brings
  « Install » back.
- « Not now » with localStorage refusing the write (Codex pass 3, coordinator's arbitration): an in-memory flag hides
  the card for the rest of the page. A cancelled native install window hides the card (accepted as the user's choice).
