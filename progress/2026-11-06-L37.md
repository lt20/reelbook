## What
`#demo` now shows the five examples of the landing mockup v3, one per notebook, with their real (generated) photos
instead of the four stick-figure sheets: spinning back kick (Fight techniques › Kicks & knees), pirouette en dehors
(Dance › Turns), diagonal stretch (Yoga & stretching › Hips), nose press on a box (Ski & snowboard › Park), push-up,
taps and jump squat (Strength › HIIT). One session, « Sampler », chains them with the mockup's doses.
Kitesurf leaves the demo. No change to the app's code or to the schema of `catalogue.json`.

## Why
The landing (L30) sends visitors to « See a demo »: the demo should show the same sheets as the landing.

## Decisions
- Template per notebook profile (`app/config.js`), like a real sheet: `technique.html` for fight (partner) and
  snow (technique), `sheet.html` for dance, yoga and strength (gym).
- Only the mockup's text is used: title, six steps (name + cue), alt texts, provenance line. Omitted, not invented:
  catalogue `summary`; sheet eyebrow, lead, kit; Why, Dose, Key points, loop line (sheet.html); Prerequisites,
  Conditions, Roles, Go / no-go, Common mistakes, Key points, Try plan, Safety, Control / tap (technique.html).
- Footer = « Generated demonstration » + the mockup's provenance sentence (`drawn`), no author name.
- Session: no `notebook` field (the app does not read it, and the session spans five notebooks).
- Thumbnails: the example's own card image from the mockup (`items.<key>.img`): `t-coup-de-pied-tournant-foie`,
  `c-pir`, `st05`, `sb05`, `hi04`; resized with `sips -Z 240` (no crop, long side 240 px). Photos `sips -Z 640`
  → 512 × 640, JPEG quality 70, original file names kept.
- `scripts/demo-drawings.py` deleted (it only drew the placeholders).

- Coordinator's arbitration on Codex pass 2 (6 Nov): option (a), `DEMO = 'rb-demo-2'` in `app/sw.js` (that line
  only, `VERSION` untouched) + `tests/demo-sw.test.cjs`; card credit shortened to « Generated demo » (`author`),
  the sheet footer keeps « Generated demonstration ».

## Pitfalls
- The branch created with `git checkout -b … origin/main` tracks `origin/main`: a bare `git push -u origin <branch>`
  went to `main` (refused by the protection). Push with `origin <branch>:<branch>`.
- The acceptance tests filtered images on `svg|png`: JPEG photos need `jpe?g` too, not only the count 4 → 5
  (separate commit, for Codex to validate). The L27 regression test `tests/demo.test.cjs` named the old slugs.
- A content swap is not offline-safe with the L27 service worker (Codex pass 2): the demo cache `rb-demo-1` is
  stale-while-revalidate, so the first online visit after the deploy still gets the old catalogue and warms only the
  old slugs; the next offline start gets the new catalogue and its sheets are missing. One-line fix proposed to the
  coordinator: `DEMO = 'rb-demo-2'` in `app/sw.js` (activate deletes the old demo cache) + `tests/demo-sw.test.cjs`.
- The worktree sandbox refuses shell loops with variables: write the script to a file and run `bash <file>`.
