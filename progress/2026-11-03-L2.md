## What
- README: app link under the title paragraph and in Quick start step 1. Python 3.9+ in the requirements and in the test line.
- docs/own-supabase.md: a paused free project has to be restored by hand from the dashboard (Project → Restore). It does not wake up when the app opens. The app shows a hint when it cannot load (L1). §5 gives the hosted URL directly.
- install.sh / install.ps1: minimum version 3.10 → 3.9.
- tools/rb.py `_ts`: Postgres timestamps with a trimmed fraction (`.12345`) were unreadable before Python 3.11. `requeue-stuck` then requeued a request claimed a minute earlier. Fixed, with a test in tests/rb-queue.test.py.

## Why
A new Mac ships `/usr/bin/python3` 3.9.6, and the installer refused it. The old docs promised that a paused Supabase project would wake up by itself, which it does not.

## Decisions
- SKILL.md has no Python version line, so it was left untouched.
- CI `python-version: '3.9'` is left to Laurent (`.github/**`).

## Pitfalls
- `datetime.fromisoformat` before 3.11 only reads 3 or 6 fraction digits. Postgres omits trailing zeros, so about 10 % of stamps hit this.
- The Bash guard of an isolated worktree refuses `for f in …; do node $f` and `$VAR` passed to python or git. Put such loops in a script under the scratchpad.
