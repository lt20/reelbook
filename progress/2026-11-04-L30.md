  harness keeps running the app script alone (English fallback `T(key, english)`, checked against the dictionary).

  « Create my notebook » opens the existing sign-up (hosted radio) or the setup screen with the project form
  (« On my own Supabase »). « Sign in » opens the existing sign-in. In-page links never touch `location.hash`
  (the app routes on it).

  vidéo. »), the aria labels the mockup left in French, the French of the auth / setup / welcome screens (the
  mockup has none). The footer keeps its first sentence only (the rest described the mockup's own photos). Natan
  Levy, credited in the mockup for the MMA frames, becomes « [compte] » like the dance example.
- `tests/acceptance/l25/presentation.test.cjs`: five cases asserted the L25 copy that L30 replaces (one-sentence
  summary, three steps, « What you need », « Create an account » on the first screen). Rewritten to the landing's
  copy with the same intent, in a separate commit, for the coordinator / Codex to arbitrate.

## Pitfalls
- `tests/l21-identity.test.cjs` checks every `transition:` up to `</style>` sits in
  `@media (prefers-reduced-motion:no-preference)`: the landing's transitions are grouped there.
- Lazy images: a full-page screenshot needs a scroll pass first, or the lower pictures are blank.
- Before L32 is pushed, `beta_seats()` answers 404 on the hosted backend: the line stays hidden, but the browser
  logs the failed request in its console (production only; the preview's fake client answers without a request).
