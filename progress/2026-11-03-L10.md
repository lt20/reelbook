## What
« Start » under the title of a session page (`#session/<slug>/play`) and of a sheet page (`#<slug>/play`) opens a
full-screen player, one exercise per screen: ✕ (back to the session or sheet page), « 2/5 » and the title, the step
photos in a 4:5 scroll-snap carousel with dots (tap: L3's viewer), the dose very large (L9's numbers, else the free
text, else nothing; the free text stays under the numbers when it says more), the first three key points, and
« ← Previous » / « Next → » (64 px, thumb zone), « Finish » on the last exercise (back to the session page; L11 adds
the end screen). Swipe left / right on the dose and key points, arrows on a keyboard. The screen stays on while
playing, whatever the toggle. The exercise reached is kept per user and session in `rb.play.<uid>`; reopening
`#session/<slug>/play` offers « Resume at 3/5 » or « Start over ». Dark by default.

## Why
Audit S1: a session is played, not read.

## Decisions
- Previous / Next redraw in place and rewrite the address with `history.replaceState`: Back leaves the player in
  one step instead of walking back through every exercise. ✕ and Finish set the hash (one history entry).
- `rb.play.<uid>` = `{<session slug>: n}`, 50 sessions at most; Finish forgets the session; the prompt shows only
  when the stored n is between 2 and the number of exercises.
- « Start » on a sheet opened from a session (`#session/<slug>/<n>`) plays the session from that exercise.
- A single sheet has no counter and no dose (no session item); its only button is « Finish ».
- Previous stays visible but disabled on exercise 1 (the thumb positions do not move).
- « Dark by default, light/dark tokens otherwise »: the player takes the dark tokens unless the light theme is
  chosen (`:root[data-theme="light"]`), by adding `.player` to the forced-dark token rule (a copy would break the
  C6 test that counts the dark token blocks).
- The carousel is 4:5 at full width but at most 46 % of the screen height (narrower, centred) so the dose stays in
  view on an iPhone.
- Helpers: `RS.playRoute / playHref / sheetPlayHref / doseLabel` (sessions.js v7), `SH.keyPoints` (sheet.js v2);
  cache `rb-shell-27`. Unit tests in `tests/player.test.cjs`.

## Pitfalls
- The harness keeps one fake element per id across renders: buttons are wired with `addEventListener` after each
  render (`onClick`), not by delegation on `#player`.
- `font:` shorthand does not satisfy the acceptance regex on `font-size`; the dose sets `font-size:64px`.
