# L1 — App fixes (C1 C2 C5 C6)

## What
- **C1** `RS.MAX` goes from `{title: 80, format: 80, dose: 40}` to `{title: 80, format: 240, dose: 60}`. The Edit
  inputs already took their `maxlength` from `RS.MAX`. Regression test: a video session with a 206-character format
  and a 51-character dose, one other dose changed, saved: format and dose written byte for byte. Checked red on the
  old limits first. In the preview, « Redresser ses épaules » (206-character format) keeps its format after an edit.
- **C2** « N more to pick from » (no plural on the phrase); the add-notebook examples are the first three library
  notebooks not added yet; static home eyebrow « Your videos, by notebook »; queue reason on its own line.
- **C5** `signUp` passes `emailRedirectTo: location.origin + location.pathname`; on a self-hosted backend a load
  error adds the paused-project sentence.
- **C6** `:focus-visible` ring, `<div lang>` around an injected sheet, `role="status"` on `#flash`,
  `aria-live="polite"` on `#count` (it holds the search result count), `--line-strong` on inputs, two
  `theme-color` metas, notch-aware side padding.

- **C1, Codex pass 1 (bloquant)**: `rb.py publish` and the schema do not enforce the limits, so a format of 241
  characters would still lose its end when an unrelated dose is saved. Edit now keeps each text as it was when it
  opened (`was`) and clips only the texts the user changed (`RS.keepOrClip`). Tests: unit + app (85-character title,
  241-character format, 61-character dose: kept whole when untouched, even moved; clipped when edited).

- **C5, Codex pass 2 (bloquant)**: `emailRedirectTo` is honoured only when the URL is allowed in the project's
  Auth URL configuration. `docs/own-supabase.md` §3 now says to set Site URL and Redirect URLs to the app address
  when Confirm email stays on (L2's file, merged before this change: no parallel conflict). The hosted project
  needs the same setting: Laurent's (dashboard, prod config).

## Decisions
- Queue « · Video »: no theme fallback exists in the code; the « Video » was the start of the failure reason
  (« Video unavailable (private account) ») joined with « · ». The reason now sits on its own line
  (`<small class="why">`, block).
- Add-notebook card when every library notebook is on: no eyebrow at all, only « Describe one yourself. »
  (coordinator's decision, 3 Nov: no « 0 more to pick from »).
- Examples: first title as is, the next two with a lower-case first letter (« Kitefoil, wingfoil, wakeboard… »):
  confirmed by the coordinator.
- Paused hint: a full stop is added after the raw error when it has none.
- Sheet language: `<html lang>` if present (none of the 32 local sheets has one), else « fr » when the text holds
  three distinct common French words (all 32 local sheets), else no attribute. The wrapper is built as a string so
  the test harness (fake DOM) keeps working.
- Contrast measured: `--line-strong` 3.04:1 on `--bg` and 3.29:1 on `--paper` (light), 3.61:1 / 3.24:1 (dark).
  The focus ring sits 2 px outside the button, on the page background (ink on bg).
