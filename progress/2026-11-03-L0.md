## What
- `scripts/codex-review.sh`, `scripts/codex-acceptance.sh`, `scripts/lib/codex.{sh,mjs}`, `scripts/codex/*`:
  the second look by Codex, ported from the protocol kit, with Reelbook prompts and protected zones.
  Kit tests ported to `scripts/tests/` (`node --test scripts/tests/`).
- `tools/preview/`: the app on a fake backend (`build.sh`, `serve.sh`, `fake-supabase.js`, `fake-data.py`,
  `make-fixtures.py`) and synthetic fixtures in `tests/fixtures/preview/`.
- `tests/e2e/shots.mjs` + `steps/smoke.json` + `README.md`, `tools/e2e-setup.sh`: iPhone 14 screenshots.
- `tests/harness.cjs`: the `app()` harness moved verbatim out of `tests/auth-flow.test.cjs`.
- `progress/README.md`: this journal format.

## Why
The Paul protocol replaces the human test by a second model's review and screenshots of the real app.

## Decisions
- Script messages, prompts and the PR comment stay in French, as in the kit, and the verdict words stay
  `ok` / `bloquant` (COORDINATION.md uses them). The app UI is untouched.
- Release, CI guard and arbitrage helpers of the kit are not ported (no `release.sh`, no workflow here).
- Acceptance tests: the kit's file filter is kept (`*.test.*`, `*.spec.*`, `*.yaml`, `*.md`); the prompt
  asks Codex for `*.test.cjs` files using `tests/harness.cjs`.
- Pillow is not in the default `python3` on this Mac: fixtures were generated with
  `/opt/homebrew/bin/python3.13`. Image labels are written without accents (Pillow's bundled font).
- `shots.mjs` names a failed request by URL (the console's « Failed to load resource » has none) and a step
  may tolerate a known app bug with `allow` + `why`.
- `?missing=<tables>` answers `PGRST205` / 404; smoke step 08 checks the Settings hint on it.

## Pitfalls
- App bug found (not fixed here, `app/` is out of scope): `loadSheet` imports the sheet's `<img>` into the
  page before rewriting `src`, so opening a sheet first requests `img/thumb.jpg` next to `index.html`
  (404, in production too). Natural home: L3 (sheet view).
- The worktree sandbox refuses compound shell commands with variables or loops: one plain command per call.
- `tests/harness.cjs` is picked up by `node --test tests/*.cjs` (counts as one passing file).
