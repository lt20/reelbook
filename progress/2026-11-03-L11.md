## What
- Session player: under the dose, one round check box per set (« 3 × 10 » → 3), or one « Done » box when the dose
  has no sets. Checks are kept per user, session and exercise in `rb.play.<uid>` (the L10 key, extended:
  `{slug: n}` becomes `{slug: {n, sets: {<exercise n>: [set numbers]}}}` once a set is checked); a checked play
  offers « Resume » even at 1/N; « Start over » and Finish clear them.
- Rest timer: checking a set (but the one that completes the last exercise) starts a countdown in place of the dose:
  item `rest_s`, else the session format (`RS.parseRest`, already folded into the resolved item by L9), else 60 s.
  « −15 s », « +15 s », « Skip ». It carries on over the next exercise. At zero: a short 880 Hz beep (Web Audio,
  the context made on the first tap of a set / rest button, with a silent note to unlock iOS) and a 600 ms flash
  of the accent colour (`#play-flash`), skipped under `prefers-reduced-motion`.
- End of session: « Finish » opens an end screen in `#view` at the session's address: « Session done », the session
  title, « N exercises · M sets », the practice-log field prefilled with that summary, « Save to log » and
  « Close ». Without the practice table (or without its read: `practiceOk`), the summary and « Close » only.

## Why
Audit S3 (sets and rest during the workout) and S4 (end of session feeding the practice log).

## Decisions
- Timer logic: `RS.restRemaining(startMs, seconds, clock)` (pure, injected clock, rounded up) and `RS.restClock`;
  the 250 ms interval only repaints. Checked with Playwright (scratchpad `L11/timer-check.mjs`): 0:30 rest, page
  hidden and frozen (`Page.setWebLifecycleState`) from 5 s to 10 s → « 0:20 » at 10.01 s; beep once at zero;
  flash 601 ms; no flash with reduced motion; AudioContext made during the tap (user activation true).
- « Save to log » and « Done today » share one write: `insertPractice(row)` (touched → localGen, 23505 as saved,
  lastDone + cached catalogue), and `logAttempt` keeps the same row id for a same-day retry of the same text.
- « exercises » in the summary counts the exercises with at least one set checked.
- The end screen keeps `<h1>{session title}</h1>` (L10's tests expect it after Finish) under a « ✓ Session done »
  eyebrow. A successful save returns to the session page (« Done today ✓ »); leaving for another page drops the
  end screen.
- −15 s taken to zero ends the rest like Skip (no beep). The rest lives in memory only (not in `rb.play`).
- Single-sheet play (`#<slug>/play`): no sets, no end screen (as before).

## Pitfalls
- The harness's `fire` calls the element's own listener with no event target and no `checked`: the change handler
  toggles from the stored state when the box has no boolean `checked`.
- The harness runs `setTimeout` at once: the ticker is a guarded `setInterval` (absent in the harness).
- In the harness only `#player`'s innerHTML string exists: the set/rest block is a `region()` repainted with the
  generalised `repaint(id, inner, root)`.
