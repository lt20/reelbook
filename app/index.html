Welcome to Reelbook

How it works

1 · Save videos on your phone

A video is worth keeping: tap + Add a video and paste the link. It waits in the queue. That is all the phone does.

2 · Claude turns them into sheets

Every now and then, when a few videos are waiting, you run the Reelbook skill on your computer. Claude opens each video, watches it, picks the key frames and writes a sheet: photos, why it matters, key points, the steps in order.

What you need on that computer

  • Claude Code (terminal, desktop app or VS Code), Pro plan or above.
  • Chrome with the Claude in Chrome extension.
  • Being signed in to Instagram, TikTok and/or Facebook in that Chrome (YouTube needs no sign-in).

How a run goes

  • Open Claude Code and type /reelbook. Claude reads your queue and processes the videos one by one.
  • Keep Chrome open, not minimised, with the video tab in front: the video does not play in the background.
  • Expect 10 to 15 minutes per sheet. You can leave the computer to it.
  • On a Mac, it can run every night instead: tools/nightly.sh install in the Reelbook folder. Leave the Mac plugged in with Chrome open; a locked screen is fine.

3 · Set up the computer, once

Paste one line in a terminal. It installs the code, the Python tools and the skill, then asks for the email and password you just chose.

You can find these lines again anytime in Settings.
