# Pirouette en dehors — série de démonstration

Six images photoréalistes générées pour illustrer un cas de danse Reelbook. Elles simulent des arrêts sur image d'un même Reel vertical ; elles ne proviennent pas d'une vidéo réelle. Ne pas les créditer comme des captures TikTok ou comme une démonstration technique certifiée.

| Fichier | Étape illustrée |
| --- | --- |
| `01-preparation-v2.jpg` | 1 · Préparation en quatrième |
| `02-montee-retire.jpg` | 2 · Relevé, retiré |
| `03-premier-quart.jpg` | 3 · Le regard fixe un point |
| `04-rotation-regard.jpg` | 4 · Le tour |
| `05-sortie.jpg` | 5 · Le retour de la tête |
| `06-reception-v2.jpg` | 6 · Réception en quatrième, bras ouverts |

Format : JPEG, portrait 4:5. Usage prévu : grande image de la fiche et miniatures du déroulé. `03-premier-quart.jpg` convient aussi à l'image de la section « Tes notes ». `card.jpg` est la version horizontale 3:2 pour le carnet, la recherche et la séance.

Les fichiers `01-preparation.jpg` et `06-reception.jpg` sont les premières versions conservées pour comparaison ; utiliser les variantes `-v2` pour la maquette. Elles rendent le plié plus visible.

Génération : outil imagegen intégré. Prompt de base : « photo réaliste d'une danseuse adulte en justaucorps bordeaux, short noir, collants et chaussons roses, dans un studio lumineux avec fenêtre et miroir ; cadrage vertical plein pied, lumière naturelle, texture d'une vidéo prise au téléphone, sans texte ni interface ». Les cinq autres prompts réutilisent l'image précédente comme référence de personnage, tenue, lieu et cadrage, puis demandent successivement la montée en retiré, le premier quart de tour, la rotation avec le regard, la sortie et la réception.
