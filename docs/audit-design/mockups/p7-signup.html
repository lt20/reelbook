    Ton ordinateurYour computerÀ faireTo do

    C’est lui qui transforme tes vidéos en fiches. Il te faut Claude Pro ou plus avec Claude Code, Chrome avec l’extension Claude in Chrome, Git et Python 3.9+.It is what turns your videos into sheets. You need Claude Pro or above with Claude Code, Chrome with the Claude in Chrome extension, Git and Python 3.9+.

    Colle cette ligne dans le Terminal. Elle installe le skill /reelbook et le relie à ton compte.Paste this line into Terminal. It installs the /reelbook skill and links it to your account.

    curl -fsSL https://lt20.github.io/reelbook/install.sh | bash

    Lire le script avant de le lancer ↗Read the script before you run it ↗

    Tu retrouves cette ligne à tout moment dans Settings.You can find this line again anytime in Settings.

  3. 3

    Ton téléphoneYour phoneÀ faireTo do

    Mets Reelbook sur ton écran d’accueil, puis le raccourci « Envoyer à Reelbook » dans le menu Partager de l’iPhone. Sur Android, colle simplement le lien dans l’app.Put Reelbook on your home screen, then the “Send to Reelbook” shortcut in the iPhone Share menu. On Android, just paste the link in the app.

  4. 4

    Ta première vidéoYour first videoÀ faireTo do

    Partage une vidéo depuis Instagram, TikTok, YouTube ou Facebook, ou touche + Add a video et colle le lien. Elle attend dans la file jusqu’au prochain /reelbook.Share a video from Instagram, TikTok, YouTube or Facebook, or tap + Add a video and paste the link. It waits in the queue until the next /reelbook.

Comment ça marcheHow it works

Envoie, depuis le téléphoneSend, from your phone

Une technique te plaît dans ton fil : Partager, Reelbook. La vidéo attend dans la file. Le téléphone ne fait rien de plus.A technique catches your eye in your feed: Share, Reelbook. The video waits in the queue. That is all the phone does.

Lance, sur l’ordinateurRun, on your computer

Tape /reelbook dans Claude Code quand tu veux. Garde Chrome ouvert et devant, connecté à Instagram, TikTok ou Facebook si tes vidéos en viennent (YouTube ne demande rien). Claude regarde chaque vidéo et écrit la fiche : photos, pourquoi, points clés, étapes dans l’ordre. Sur un Mac, il peut aussi tourner chaque nuit tout seul : tools/nightly.sh install dans le dossier Reelbook.Type /reelbook in Claude Code whenever you like. Keep Chrome open and in front, signed in to Instagram, TikTok or Facebook if your videos come from there (YouTube needs nothing). Claude watches each video and writes the sheet: photos, why, key points, the steps in order. On a Mac, it can also run every night on its own: tools/nightly.sh install in the Reelbook folder.

Organise et entraîne-toiOrganise and train

Déplace une fiche d’un groupe à l’autre, ajoute tes notes, compose une séance à partir de plusieurs carnets. Sur le tapis, ouvre la fiche : le geste d’abord, en images. Coche Done today.Move a sheet to another group, add your notes, build a session from several notebooks. On the mat, open the sheet: the move first, in pictures. Tick Done today.
