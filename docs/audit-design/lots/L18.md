# L18 — Bottom sheets instead of centred dialogs (E8)

- Under 600 px wide, every `dialog.dlg` is a sheet anchored at the bottom: full width, top corners 14 px, bottom
  padding `env(safe-area-inset-bottom)`, slide-up entry (none with reduced motion), backdrop tap closes (unless the
  dialog has unsaved input).
- Sheet header: « Cancel » left | title | primary action right (bold); the bottom button pair goes (keep it ≥ 600 px).
- No autofocus on a text field when a dialog opens (the keyboard hid the list and the action in « New session »).
- Height bounded by the visual viewport: a CSS variable `--vvh` updated on `visualViewport.resize`, so the sheet
  stays above the keyboard; one scroll container per sheet (no nested scroll).
- Destructive confirmations become action sheets: the danger action in red on top, « Cancel » below, separated.
- A small helper (`openSheet(dlg)`/`closeSheet`) used by all dialogs; guarded for the test harness (`showModal` may
  be missing).
