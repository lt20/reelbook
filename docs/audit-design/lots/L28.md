# L28 — Capture in one gesture (O5) — protected zone (schema + Edge Function)

Saving a video means copying the link, opening Reelbook, tapping + and pasting. iOS has no Web Share Target for PWAs.

## Step A (app only)
- In the Add a video sheet: a « Paste link » button that reads the clipboard (`navigator.clipboard.readText`), fills
  the field when it holds a supported link, and says so otherwise. Opened from the floating + with a link already in
  the clipboard (permission permitting), the field is pre-filled but never sent without a tap.

## Step B (shortcut, needs Laurent's deploy)
- `supabase/schema.sql`: table `capture_tokens` (`id`, `user_id`, `token_hash`, `label`, `created_at`,
  `last_used_at`, `revoked_at`), RLS own rows; tokens stored hashed (sha-256), shown once.
- `supabase/functions/add-link/index.ts`: `POST {url, note?}` with `Authorization: Bearer <token>`; looks the token up
  by hash with the service role, refuses revoked/unknown, validates the link like the app, inserts a `requests` row for
  that user, rate-limited (10 per minute per token). No other route.
- Settings › « iPhone shortcut »: create a token (label), copy it once, revoke; step-by-step text to build the iOS
  shortcut (Share Sheet → Get URLs → Get contents of URL POST). No downloadable `.shortcut` file.
- **Laurent deploys**: `db push` of the table and `supabase functions deploy add-link`. Until then Settings hides the
  section (feature detected by a failing select on `capture_tokens`).
