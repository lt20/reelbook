# L23b — backfill-tags heuristic, second pass (after Laurent's dry run, 4 Nov)

Laurent's `rb.py backfill-tags --dry-run` on his account (110 sheets, slugs and tags only, nothing else read): gear
empty on ~100 sheets, type empty on ~98, wrong zones on fighting / board-sport sheets. Fix `derive_tags` (and its
tests) so the dry run is worth writing.

- **Type** falls back, in order: keyword in title/group/slug (`session-echauffement-…` → warm-up, `…-mobilite-…` →
  mobility, `routine` → routine, `etirement`/`stretch` → stretch); then the notebook's profile: `technique` → skill,
  `partner` → skill; then the notebook: `strength` → strength, `yoga` → stretch; else empty. Use the slug and the
  session slug part as text (exercise sheets of a session carry it: `session-<session>-<anchor>`).
- **Zone**: none for notebooks whose profile is `technique` or `partner` (a kick is not a « knees » exercise, a foil
  tack is not « ankles »). Library group names that are not body areas never map to a zone (« Kicks & knees »).
  Prefer arms over core for `pompe-triceps` (triceps beats « pompe »/core); `pompes` (push-ups) → chest.
- **Gear**: add vocabulary values `plate` (disque, disc, plate), `cable` (poulie, cable, pulley), `machine` (smith,
  machine), `bench` (banc, bench) to `facets.gear` in `app/config.js`; French keywords from slugs too
  (`halteres` in `session-dos-2-halteres-*` → dumbbell for each exercise of that session).
- Fixture: the slug list of the dry run (in the lot's test file, slugs and expected tags only) as a regression table;
  measured before/after: count of empty gear / empty type / zone on technique sheets.
