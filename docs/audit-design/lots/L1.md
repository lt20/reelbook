# L1 — App fixes: format truncation, copy bugs, sign-up redirect, accessibility base (C1 C2 C5 C6)

## C1 — Saving a session edit truncates its format (data loss)
- Today `app/sessions.js` has `MAX = {title: 80, format: 80, dose: 40}` and `saveEdit` clips with `RS.clip`
  (`app/index.html` ~1028). The 11 video sessions have formats of 97 to 206 characters; 2 of 75 doses exceed 40.
  Editing a single dose and saving cuts the format silently.
- Expected: `format` up to 240, `dose` up to 60, `title` stays 80. Inputs carry `maxlength` equal to the limit so a
  user never loses text silently. A video session with a 206-character format, edited (one dose changed) and saved,
  keeps its format byte for byte.
- Tests: regression test in `tests/sessions.test.cjs` / `tests/auth-flow.test.cjs` for the save path.

## C2 — Copy bugs
- « 25 more to picks » (`plural(n, 'more to pick')`): read « 25 more to pick from » (singular « 1 more to pick from »).
- The add-notebook card suggests « Kitesurf, cooking, pilates… » even when Kitesurf is already a notebook: build the
  example from the first three library notebooks the user has not added.
- « Three notebooks, one place » (setup/intro screen, ~line 261) is obsolete: replace by « Your videos, by notebook ».
- Queue row of a failed request reads « added 1 Nov · Video » then the reason: when a request has no theme, print no
  theme label at all (the « · Video » fallback reads like a notebook name). The reason keeps its own line.

## C5 — Sign-up redirect and paused projects
- `signUp` passes `options: {emailRedirectTo: location.origin + location.pathname}` so a confirmation e-mail never
  lands on Supabase's default `localhost:3000`.
- When loading the catalogue fails **on a self-hosted backend** (`backend.mode === 'own'`), the error line adds:
  « Your Supabase project may be paused: open your Supabase dashboard and restore it. »

## C6 — Accessibility base
- `:focus-visible { outline: 3px solid var(--ink); outline-offset: 2px }` on links, buttons, inputs, summary, cards
  (the default ring is invisible on the blue buttons).
- Injected sheet HTML gets a `lang` attribute: the sheets are French today but carry none. Rule: wrap the injected
  sheet in `<div lang="…">` using, in order, the sheet document's `<html lang>` if present, else a light detection
  (French if the text contains common French words/accents — keep it simple and tested), else no attribute.
- `#flash` gets `role="status"`; the search result count gets `aria-live="polite"`.
- Inputs: a `--line-strong` token for input/textarea/select borders, ≥ 3:1 against their background
  (`#8f8a80` light, `#6b7079` dark).
- `theme-color`: two `<meta name="theme-color">` with `media="(prefers-color-scheme: light|dark)"` using the page
  background (`#f3f1ec` / `#15171a`); manifest unchanged.
- Side padding respects the landscape notch: `padding-inline: max(16px, env(safe-area-inset-left/right))` where the
  16 px gutter is set.
