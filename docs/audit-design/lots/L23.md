# L23 — Faceted library: structured tags across notebooks (O7) — schema change

Laurent wants « shoulders · band · under 10 min » across all notebooks; today search is free text (L14) and the only
structure is notebook › group.

- **Tags**, a fixed vocabulary in `app/config.js` (`facets`):
  - `zone` (body area: shoulders, arms, chest, back, core, hips, legs, knees, ankles, neck, full body),
  - `gear` (none, mat, band, dumbbell, kettlebell, barbell, bar, rings, ball, foam roller, chair, wall, board, kite…),
  - `minutes` (a number, from `duration`; buckets « < 5 », « 5–10 », « 10–20 », « 20+ »),
  - `type` (strength, mobility, stretch, cardio, skill, drill, warm-up, routine).
  A sheet holds `tags: {zone: [], gear: [], minutes: n|null, type: ''}`.
- `supabase/schema.sql`: additive `alter table public.sheets add column if not exists tags jsonb not null default
  '{}'::jsonb;` (+ GIN index). **db push by Laurent** (decision 3). The app and `rb.py` work on a backend without
  the column (fall back silently: no facets, no error).
- Skill (`skill/reelbook/SKILL.md`): writes `tags` in `meta.json` from the vocabulary only (one line per facet in the
  rules); `rb.py publish` validates against `facets` (unknown value = refused on a new sheet, warning on an update) and
  sends the column; retries without it when the backend has no column (as L14 for `search_text`).
- `rb.py backfill-tags [--dry-run]`: tags existing sheets **without Claude** (decision 6), from what is already there:
  group → zone (library mapping), keywords of `search_text`/title → gear and type, `duration` → minutes. Writes to
  production: **Laurent runs it** (decision 5 precedent). Tested on fixtures.
- App: in the search view (L14), a row of facet chips (Zone, Gear, Time, Type) under the field; each opens a bottom
  sheet (L18) with the values present in the catalogue and their counts; chosen values combine (AND across facets, OR
  inside one) with the text query, across all notebooks; results as photo cards (L12) with their notebook. Chosen
  facets in the URL hash so Back works (L17). Sheets without tags only match when no facet is chosen.
