# L26 — Installation you can tap (O2)

The install line shown in Settings carries the backend URL and key: long, different for everyone, painful to send from
a phone to a computer.

- `app/install.sh` and `app/install.ps1` without `--url/--key` use the hosted backend: they read `hosted.url` and
  `hosted.anonKey` from the published `config.js` (`https://lt20.github.io/reelbook/config.js`, parsed without
  executing it). With arguments: unchanged. Hosted empty in config → clear message asking for `--url/--key`.
- Settings: on the hosted backend the line becomes the short one, identical for everyone; on an own backend it keeps
  the arguments.
- « Send to my computer »: Web Share (`navigator.share`) of the line plus one sentence; fallback `mailto:` with the
  line in the body.
- README Quick start and `docs/manual-install.md` updated.
