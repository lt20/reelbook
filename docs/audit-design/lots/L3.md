# L3 — Sheet in use: keep the screen on, gesture first, full-screen photos (Q1 Q3 Q4)

Context: at the gym the phone lies on the floor; between two sets the user glances at the photo, the dose and two or
three cues. Today the screen locks after 30–60 s and the first photo of the movement is 2.2–2.8 screens down.

## Q1 — Keep screen on
- A toggle « Keep screen on » in the top bar of sheet and session pages (with the existing Move / Edit buttons).
- On: `navigator.wakeLock.request('screen')` in try/catch; re-request on `visibilitychange` back to visible while
  still on a sheet or session page; release when leaving those pages or when turned off.
- Preference remembered in `localStorage` (`rb.wake`): once on, every sheet/session page asks for the lock.
- Hidden when `'wakeLock' in navigator` is false. Pressed state visible (`aria-pressed`).

## Q3 — Gesture first, reordered at display time
- Do **not** regenerate sheets. In the view (after `loadSheet` parses the HTML), reorder blocks of sheets built from
  `templates/sheet.html` and `templates/exercise.html`: header (title, lead, kit) → **sequence / steps with photos**
  → **dose** → **first 3 key points** → remaining key points in a `<details>` whose summary reads « +N more »
  → **why** block (and the note attached to it) in a `<details>` collapsed, summary = the sheet's own heading text
  (e.g. « Pourquoi ») → everything else in its original order (variant, source, credits).
- Inspect both templates and several real sheets (read-only, Laurent's local folder
  `/Users/laurentthevin/dev/reelbook/work/*/index.html`, never copied into the repo) to find robust selectors. When a
  block is not found, leave that part of the sheet as is: never drop content.
- Session pages are not touched here (L5).

## Q4 — Full-screen photo viewer
- Tapping a step photo opens a viewer: `<dialog>` on black, the sheet's step photos side by side in a horizontal
  `scroll-snap-type: x mandatory` strip, starting at the tapped photo, the step caption under each photo, a close
  button ≥ 44×44 pt, Escape closes, focus returns to the tapped photo.
- `prefers-reduced-motion`: no smooth scrolling.
