A visitor cannot see what a sheet looks like without installing Claude Code and processing a video.

- `#demo` (or `?demo`): a read-only notebook served from static files in `app/demo/` (`catalogue.json`, one folder per
  sheet with `index.html` and `img/`, one session), no backend, no account. Banner « Demo · read only · Create an
  account », editing controls hidden (Move, Delete, Edit, notes, Done today, Add to session).
- Content: **4 sheets and 1 session made from footage Laurent films himself** (decision 4). Until he does, the lot
  ships placeholder content drawn for Reelbook (SVG/PNG generated, no frame from any video) so the mechanism is
  complete; swapping the content = replacing `app/demo/` files, no code.
- The service worker caches the demo on first visit; the demo never writes to `localStorage` keys of a real account.
