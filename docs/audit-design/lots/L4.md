# L4 — Queue and polish: queue states, retry, tap targets, danger colour, session format (Q6 Q7 Q8)

## Q6 — A readable queue
Data: `requests` rows `id,url,status,theme,note,created_at` (+ `processed_at`, to add to the select). RLS allows
select/insert/update/delete of own rows.
- Three distinct states:
  - `queued` → neutral pill « Waiting » (grey: `--tag` / `--ink`);
  - `processing` → accent pill « Processing » and « since HH:MM » (from `processed_at`, local time);
  - `error` → danger pill « Failed », the reason (`note`) on its own line, actions « Retry » and « Remove ».
- Retry: `update({status: 'queued', note: null, processed_at: null})` on that row; on success the row shows
  « Waiting »; on failure an inline error, the row unchanged.
- A queued request older than 7 days adds « waiting N days ».
- The queue collapses into one summary row: « 3 in the queue · 1 failed » (failed count in danger colour) with a
  chevron; a `<button aria-expanded>`; collapsed by default; expanded state remembered in `localStorage`
  (`rb.queueOpen`). Empty queue: no row.
- Computer status, shown inside the expanded queue: one query for the latest `done` request (`processed_at`
  desc, limit 1). None ever → « No computer has processed a video yet. » + link « Set up your computer » to
  `#welcome`. Otherwise → « Last run: <relative time> » (« today », « yesterday », « 5 days ago »).

## Q7 — Tap targets and danger colour
- Tokens `--danger` (`#b42318` light, `#f97066` dark) and `--danger-bg`; `.btn.danger` and the delete dialogs use
  them. « Delete sheet » / « Delete session » become text buttons in `--danger`.
- Every tappable control ≥ 44×44 px: `.btn.sm`, `.mv`, top-bar back links and « Settings », « + New session », the
  queue remove control (inline-flex + padding; no layout jump).
- Pressed state: `-webkit-tap-highlight-color: transparent` and an `:active` style (opacity .6 or scale .97).
- Removing a queue item is deferred: the row disappears, a toast « Removed · Undo » stays 5 s; the delete is sent
  when the toast ends (or on `pagehide`); Undo restores the row and sends nothing.

## Q8 — Session format out of the pill
- On session cards the `format` sentence (97–206 characters) is rendered in a round pill and makes a 5-line blob.
  Render it as a plain line `.card .fmt` (muted, 2 lines max with `-webkit-line-clamp`). Pills stay one line with
  an ellipsis.
