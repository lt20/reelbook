# L15 — Skill writing rules (E5)

Only `skill/reelbook/SKILL.md` and `templates/*.html` (and `tools/rb.py` if a check is added). No app code. Effect:
new sheets only (existing ones are not reprocessed).

- `duration` = practice time (« 5 min »), empty otherwise. Never video length, never a step count. Add `steps`
  (integer) when relevant; the app shows `duration` only.
- Eyebrow (sur-titre) of a sheet: the fine target and the duration only (« Biceps · 5 min »), never the notebook
  nor the group (they are shown by the app).
- No « closest notebook »: when no notebook of the account fits, do not publish; `rb.py error <id> "No notebook fits:
  add <suggestion>?"`. (A pizza was filed in Strength › Cooking.)
- One label per function across both templates: « Dose », « Étapes » / « Steps » (in the content language),
  « Points clés », « Plus facile / plus dur ». Update `templates/sheet.html` and `templates/exercise.html` and the
  translation table in the skill.
- Key points: the 3 most important first (the app shows 3, L3), 8 at most in total.
- The wrong movement never goes into the numbered sequence: a section « Erreurs fréquentes » / « Common mistakes »
  after it, with class `step bad`; the app styles `.step.bad` with a danger border and a « ✕ » badge (small CSS in
  `app/index.html`, in a block commented « L15 »: the only app change allowed).
- Production notes (« la légende de la publication est vide… ») go to the footer with the source, not under « Why ».
