# L38 — #demo v2 dressing: the demo looks like the real app (P6, decided 6 Nov)

Today `#demo` (L27) is a flat grid of cards, in English only. Laurent finds it « vraiment dégueulasse »: it must look
like the app a visitor would get after signing up. Content stays L37's job (`app/demo/**`, same `catalogue.json`
schema); this lot changes only how the demo is drawn.

## Scope
- **Demo home = a real account's home**: the notebooks as `.tcard` cards (colour band, round pictogram from
  `app/icons.svg`, counter, photos), colour and pictogram taken from the library of `app/config.js` by the notebook id
  (`libById`); then the sessions as in the app (a row of session cards, not a grid).
- **A demo notebook page = the real notebook page**: the cover (band, pictogram, large title), its counter, the
  Sessions row, then one horizontal row of photo cards per group (decision 7), group chips when there are two groups
  or more. Address `#demo/notebook/<id>`.
- **A sheet and the session reuse the real pages' rendering** (sheet html arranged by `sheet.js`; session header,
  format, why, numbered exercise cards with their dose). A sheet opened from the session shows its place and dose
  and previous / next, as in the app.
- Reuse the existing components and CSS (`.tcard`, `.portal`, `.group-row`, `.group-chips`, `.card`, `.seat`,
  `.seq`); only what is scoped by id in the real page (`#home`, `#groups`) gets a `.demo` twin.
- **Banner**: still the only way to sign up, read only, in the language chosen on the landing (L30 mechanism: same
  `rb.lang` key, same dictionary `window.RBL`). FR « Démo · lecture seule · Créer un compte » / « Démo · lecture seule
  · Revenir à mes carnets »; EN the current texts. The sheets' content stays English. No other new text; if one is
  needed, the control stays inactive and the PR says so.
- **L27 behaviours unchanged**: editing controls always hidden (Move, Delete, Edit, notes, Done today, Add to
  session), no write to a real account's `localStorage` keys, opens without a backend.
- Service worker: bump `VERSION` in `app/sw.js`.
