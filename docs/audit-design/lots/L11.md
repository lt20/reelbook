# L11 — Player: sets, rest timer, end of session (S3 S4)

## Sets
- Under the dose, one round check box per set when the dose has `sets` (L9): « 3 × 10 » → 3 boxes. No sets but
  `seconds` → one box « Done ». Nothing parsed → one box « Done ».
- Checked state kept per user, session and exercise for the current play (cleared by « Start over » or after finishing).

## Rest timer
- Checking a set (not the last of the last exercise) starts a rest countdown: duration = item `rest_s`, else
  `RS.parseRest(session.format)`, else 60 s. Big countdown replaces the dose; « −15 s », « +15 s », « Skip » buttons.
- At zero: a short beep (Web Audio, created on the first user tap so iOS allows it) and a full-screen flash of the
  accent colour for 600 ms (iOS has no Vibration API). Respect `prefers-reduced-motion` (no flash, only the beep).
- The timer uses timestamps (`Date.now()` at start), not a counting interval, so a locked screen or a background tab
  shows the right time on return.

## End of session
- « Finish » on the last exercise opens an end screen: « Session done », number of exercises and sets checked, the
  practice log field of L6 prefilled with a summary (« 5 exercises · 14 sets »), « Save to log » writes a
  `practice_log` row for `session/<slug>` (same code path as « Done today »), « Close » without saving.
- When the practice table is missing, the end screen shows only the summary and « Close ».
