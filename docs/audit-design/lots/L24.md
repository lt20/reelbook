# L24 — Invitation to install the app (O4)

The app works best installed (keep screen on, rest timer, full screen), but nothing says so.

- When the app is **not** running installed (`display-mode: standalone` false and `navigator.standalone` not true) and
  the user is signed in with at least one sheet: a quiet card at the top of the home page.
  - iOS Safari: « Install Reelbook: tap Share, then Add to Home Screen » with the share glyph drawn inline.
  - Android / desktop Chromium: listen to `beforeinstallprompt`, show an « Install » button that calls `prompt()`.
  - Other browsers: nothing.
- « Not now » hides it for 30 days on this device (`rb.install.dismissed`, a date; device-level, not per user).
- Never on the auth screen, never during a session player or on a sheet.
