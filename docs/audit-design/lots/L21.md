# L21 — Notebook identity: a cover per notebook (O8)

Today every notebook looks the same apart from a coloured dot: on the home page you read titles, you do not recognise
places.

- `app/config.js`: each library notebook gets `icon: '<name>'`, a pictogram from a small set drawn for Reelbook
  (`app/icons.svg`, one `<symbol id="nb-<name>">` per pictogram, 24×24, stroke 1.75, `currentColor`, no third-party
  icon font, no licence question). One pictogram per library notebook (29), plus `custom` for a notebook an account
  described itself. Existing ids, colours, groups and profiles do not change (protected-zone check, as L16).
- Home: each notebook card shows a **cover**: the notebook colour as a tinted band (light and dark tokens from the
  palette `--p0…--p7`, contrast AA for the title on it) with its pictogram, the title and the counter as today.
- Notebook page: the header takes the same cover (band + pictogram + title), compact once the page scrolls under the
  sticky bar (L17).
- Add a notebook (library list) shows each pictogram next to its title.
- `aria-hidden="true"` on the pictograms (the title says it all). Reduced motion respected.
- Service worker: `icons.svg` in `SHELL`, cache `VERSION` bumped.
