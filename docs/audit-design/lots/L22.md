# L22 — Session headings in the content language (O6, quick version)

Decision 2 (3 Nov): the interface stays in English; only the headings the app draws **inside content** follow the
language of that content. Today a French session reads « Why », « Key points », « Format » above French text.

- The app already guesses a sheet's language (`sheetLang`, L1). Extend it to a session: the session's own text (why,
  key points, format, titles) decides, same rule (`fr` when at least three distinct common French words, else `en`).
- Headings drawn by the app inside a session page and the session player (L10/L11): Why / Pourquoi, Key points /
  Points clés, Format / Format, Exercises / Exercices, Dose / Dose, Rest / Repos, Sets / Séries, and the end screen
  of the player when it quotes the session. A small dictionary `{en, fr}` in `app/sessions.js` (bump `?v=`, `SHELL`,
  cache `VERSION`); unknown language → English.
- The block gets `lang="fr"` (screen readers, hyphenation), as sheets already do.
- Buttons, menus, toasts, Settings stay English (the interface).
