# iPhone screenshots of the app (agent tooling)

No human tests a lot before it merges (`docs/audit-design/COORDINATION.md`): the agent shows its work as
screenshots of the real app, in an iPhone 14 viewport, light and dark, on a fake backend. Nothing here
ships: `app/` is copied, never modified.

## Once per machine

```sh
tools/e2e-setup.sh     # playwright@1.63.0 into ~/.cache/reelbook-e2e (no package.json in the repo)
```

## In a lot's worktree

Each lot has its own port (L0 8770, L1 8771 … L8 8778) and writes only in its scratchpad folder.

```sh
export PATH="$HOME/.nvm/versions/node/v20.20.2/bin:$PATH"
OUT=<scratchpad>/<LOT>                       # never inside the repository

tools/preview/build.sh "$OUT/preview"        # app/ + fake backend + synthetic data
tools/preview/serve.sh "$OUT/preview" 8771 & # 127.0.0.1 only; stop it when done (kill %1)

node tests/e2e/shots.mjs --base http://127.0.0.1:8771/index.html --out "$OUT/shots/light"
node tests/e2e/shots.mjs --base http://127.0.0.1:8771/index.html --out "$OUT/shots/dark" --dark
```

Rebuild after each change to `app/` (`build.sh` copies; it refuses to write into a folder that is not a
previous preview). Each run writes `<name>.png` per step and `report.json`; it exits 1 when a step has a
page error, a console error, a failed request (a missing photo included) or an action that cannot run.

- **Steps**: `tests/e2e/steps/smoke.json` (sign-in, home, notebook, sheet, session, settings, add-video panel,
  settings on a backend without the `sessions` table). A lot adds its own file, e.g.
  `tests/e2e/steps/l3.json`, and runs it with `--steps`. Format: see the header of `shots.mjs`.
  `--only <name>` reruns one step.
- **Fake backend** (`tools/preview/fake-supabase.js`): reads `vendor/fake-data.js`, keeps writes in memory
  (a reload starts over). `?noauth` shows the sign-in screen; `?missing=sessions,practice_log` makes those
  tables answer like a backend where they were never created (`PGRST205`, HTTP 404).
- **Data**: synthetic by default (`tests/fixtures/preview/`, regenerated by
  `tools/preview/make-fixtures.py`, which needs Pillow). `build.sh <out> --work ~/dev/reelbook/work` uses
  Laurent's local sheets instead: never commit those screenshots, their photos are frames from
  third-party videos.
- **Screenshots stay in the scratchpad.** Attach the ones that matter to the PR description; do not commit
  them.
